# Beispiel-Projektprofile

Vorlagen für Projektprofile (Adapter). Der Mechanismus wird in **BRIDGE-010**
implementiert; ein read-only Dorfschaft-Adapter konzeptionell in **BRIDGE-011**.

Ein Projektprofil kennt u. a.:

```
project_id · repository · default_branch · worktree_root · allowed_machines
· default_model_policy · git_policy · migration_policy · test_policy
· handover_policy · task_number_prefix
```
